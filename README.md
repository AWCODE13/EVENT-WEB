# AMIKOM EVENT HUB

Sistem Manajemen Event Berbasis Web yang dikembangkan untuk membantu pengelolaan acara, pendaftaran peserta, dan informasi kegiatan secara terpusat.

## Deskripsi

AMIKOM EVENT HUB merupakan aplikasi berbasis web yang dirancang untuk memudahkan pengelolaan berbagai kegiatan dan event. Sistem ini menyediakan fitur manajemen event, pendaftaran peserta, pengelolaan kategori acara, serta dashboard administrator untuk memantau seluruh data kegiatan.

## Fitur Utama

* Manajemen Event
* Informasi Detail Acara
* Registrasi Peserta Event
* Dashboard Administrator
* Manajemen Pengguna
* Manajemen Kategori Event
* Pengelolaan Partner Event
* Monitoring Data Event

## Cara Menjalankan Proyek

Clone repository:

```bash
git clone https://github.com/USERNAME/REPOSITORY.git
```

Masuk ke folder proyek:

```bash
cd nama-folder-proyek
```

Install dependency:

```bash
composer install
```

Salin file environment:

```bash
cp .env.example .env
```

Generate application key:

```bash
php artisan key:generate
```

Konfigurasikan database pada file `.env`, kemudian jalankan:

```bash
php artisan migrate
```

Jalankan aplikasi:

```bash
php artisan serve
```

## Tujuan Pengembangan

Proyek ini dikembangkan untuk memberikan solusi pengelolaan event yang lebih efektif, memudahkan proses pendaftaran peserta, serta membantu administrator dalam mengelola informasi kegiatan secara terstruktur.
